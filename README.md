# EdgeEver Canvas Board

> 专为 EdgeEver 打造的原生二维无限白板与架构思维画布插件。
> 无缝扩展左侧边栏「更多类型 ▾」新建笔记菜单，提供可无限缩放平移的架构画布、便签卡片、流程图形状、智能吸附连线与 100% 离线静默自动保存。

---

## ✨ 核心特性

- 🎨 **无缝扩展「更多类型 ▾」新建笔记**：深度对接 EdgeEver 左侧边栏新建逻辑，在下拉菜单中直接增添「🎨 无限画布」选项，点击即可秒级生成画布专用笔记！
- 🗺️ **无限缩放与平移视口 (Infinite Canvas)**：
  - 支持键盘空格键 + 鼠标左键拖拽平移，或鼠标中键/右键漫游；
  - 鼠标滚轮以指针为中心自由缩放（20% ~ 300%）；
  - 现代细腻点阵背景 (Dots Grid)，缩放时平滑过渡。
- 📝 **便签卡片系统 (Sticky Notes)**：
  - 提供蓝、绿、琥珀、紫、红等多种经典便签色彩；
  - 双击卡片标题或正文即可就地编辑文字与架构说明；
  - 右下角配备平滑尺寸缩放手柄 (Resize Handle)。
- 📐 **几何形状与流程图节点**：
  - 矩形分组容器框 (Rect)
  - 圆形状态节点 (Circle)
  - 菱形条件分支判断 (Diamond)
  - 独立自由文本标签 (Text)
- ➡️ **智能贝塞尔箭头连线 (Smart Connectors)**：
  - 节点四周自适应连接锚点 (Ports)；
  - 拖拽或点击即可在两张卡片之间建立平滑贝塞尔曲线连线，带自定义文字标签（如 `HTTP POST`、`BAPI 调用`、`RFC`）；
  - 移动卡片时，连接线自动跟随联动！
- 💾 **100% 离线静默自动持久化**：
  - 画布数据以标准纯文本 JSON 代码块格式保存在笔记正文（`contentMarkdown`）中；
  - 任何移动、编辑操作均在毫秒级自动节流保存，断电或关闭笔记永不丢失；
  - 支持右上角一键切换「🎨 画布视图」与「📄 Markdown 源码视图」。
- 📸 **高清图片导出 (Export PNG)**：
  - 一键将整张架构白板导出为超清 PNG 图片，直接写入系统剪贴板或下载保存。

## 🚀 安装与分发指南

### 方式一：通过 GitHub 仓库安装（推荐）

1. 打开 **EdgeEver 客户端**，进入「**插件市场**」；
2. 在地址栏输入 GitHub 仓库地址：
   ```text
   https://github.com/zyhcs/edgeever-canvas-board
   ```
3. 点击「**安装**」即可完成部署！

### 方式二：本地开发调试

在 EdgeEver 插件管理中开启「开发者模式」，选择本项目的根目录即可实时载入调试。
