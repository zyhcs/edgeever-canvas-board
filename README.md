# EdgeEver Canvas Board

> 专为 EdgeEver 打造的 Excalidraw 原生手绘矢量白板与架构思维画布插件。
> 无缝扩展左侧边栏「更多类型 ▾」新建笔记菜单，提供对齐官方 Excalidraw 的全套矢量绘图工具（压感画笔、橡皮擦、几何图形、调色板、开源素材库）、无限缩放平移视口与 100% 离线静默自动同步。

---

## ✨ 核心特性

- 🎨 **无缝扩展「更多类型 ▾」新建笔记**：深度对接 EdgeEver 左侧边栏新建逻辑，在下拉菜单中直接增添「🎨 无限画布」选项，点击即可秒级生成画布专用笔记！
- 🖌️ **100% 对齐官方 Excalidraw 全套矢量绘图内核**：
  - **自由涂鸦与压感画笔 (Freedraw)**：支持触控板/数位板压感笔触，丝滑手绘草图；
  - **橡皮擦工具 (Eraser)**：一键擦除笔画与任意图元；
  - **全套几何形状**：矩形、菱形、椭圆、直线、单/双向箭头连线；
  - **手绘风与平直架构风自由切换**：支持 Roughness 粗糙度调节，既能画出手绘感草图，也能一键切换为精准平直的企业级架构图；
  - **丰富的调色板与网格填充**：支持描边色、背景填充色、网格斜线 (Hachure) / 交叉线 / 实心填充；
  - **开源素材库 (Excalidraw Libraries)**：支持直接导入和使用丰富的云端图标与架构素材库（AWS、Kubernetes、流程图、UI 等）；
  - **成组与图层管理**：多选元素成组 (Group)、解组 (Ungroup)、图层置顶/置底、水平/垂直对齐分布与多角度旋转。
- 🗺️ **无限缩放与平移视口 (Infinite Canvas)**：
  - 空格键 + 鼠标左键拖拽平移，或鼠标双指平移漫游；
  - 鼠标滚轮以指针为中心自由缩放；
  - 自动沉浸式满屏排版，彻底隐藏 Markdown 格式工具栏干扰。
- 💾 **100% 离线静默自动持久化**：
  - 画布数据以标准 ````excalidraw` 代码块格式自动保存在笔记正文（`contentMarkdown`）中；
  - 任何编辑操作均在毫秒级自动节流保存，断电或关闭笔记永不丢失；
  - 右上角支持一键切换「🎨 画布视图」与「📄 Markdown 源码视图」；
  - 自动向下兼容并无缝升级早期版本的轻量卡片数据。
- 📸 **全格式导出**：
  - 支持将画布导出为高清 PNG、SVG 矢量图，或直接复制到剪贴板。

## 🚀 安装与分发指南

### 方式一：通过 GitHub 仓库安装（推荐）

1. 打开 **EdgeEver 客户端**，进入「**插件市场**」；
2. 在地址栏输入 GitHub 仓库地址：
   ```text
   https://github.com/zyhcs/edgeever-canvas-board
   ```
3. 点击「**安装**」或「**更新**」即可完成部署！

### 方式二：本地开发调试

在 EdgeEver 插件管理中开启「开发者模式」，选择本项目的根目录即可实时载入调试。
